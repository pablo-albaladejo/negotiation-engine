# docs/ — Documentación de Diseño

Documentos de diseño (architecture decision records, especificaciones, análisis).

## Propósito

Decisiones arquitectónicas documentadas: por qué el motor es determinista, por qué el parser no tiene herramientas, invariantes de seguridad, etc.

## Archivos

- **`design/`** — Subdirectorio de design docs.
- **`demo.md`** — Demostración del sistema.

## Cómo escribir una design doc

1. Problema: qué se intenta resolver.
2. Solución: opción elegida.
3. Alternativas: por qué no las otras.
4. Invariantes: qué se debe mantener siempre.
5. Testing: cómo validar.
