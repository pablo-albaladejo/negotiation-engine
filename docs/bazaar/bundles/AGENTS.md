# docs/bazaar/bundles/ — Frontend del Bazaar (copia)

Copia del frontend público de bazaar.causaprima.ai, capturada el 3 oct 2026: el index.html y los 80 ficheros de /assets/. Es la fuente del modelo de precio de los dealers en [`../site-map.md`](../site-map.md) § 8. Solo referencia: nada del repo la importa.

## Archivos

- **bazaar-frontend-2026-10-03.tar.gz** — todo el frontend (tar -xzf para abrirlo).
- **MANIFEST.txt** — sha256 de cada fichero del tar, para ver si la web cambió (shasum -a 256 -c sobre una descarga nueva).
- **PersonaEditor-CY0YsfDU.js** — editor de personas de admin: bandas de trades, vista previa de la curva de concesión, concesiones en espejo, precio de bienvenida, trickster.
- **util-CFqlaVVI.js** — frase de prompt por rasgo y tramo, palabras por respuesta y la curva.
- **useEvents-BpJ5PfZT.js** — escalera de 5 niveles (Friendly, Sharp, Collector, Tricksters, Banker).
