# Heatmap
Surplus/ZOPA by rival × role, built as a DataTable with `.nr-heat-cell` cells.

| class | range |
| --- | --- |
| `.good` | ≥ 0,60 |
| `.mid` | 0,45 – 0,60 |
| `.bad` | < 0,45: where we lose value |

- Each cell shows its value in text, so the colour is never the only signal.
- Keep to three bands. There is no continuous gradient.
