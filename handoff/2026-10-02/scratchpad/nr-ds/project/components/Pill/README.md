# Pill
A rounded label for a final state.

- `.nr-pill.verdict`: a candidate is promoted.
- `.nr-pill.rejected`: a candidate is not promoted, with the reason.
- `.nr-pill.sample`: a mono badge beside the page title when the data are examples.

The promotion verdict follows one rule: better surplus/ZOPA **and** 0 mandate violations. It is computed from the arena metrics, never typed by hand.
