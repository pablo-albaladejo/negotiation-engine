# MatchSelector
A wrapping row of match buttons (`.nr-matches` > `button.nr-match`). Each shows the match id, the rival, and the result in mono.

- The selected match is `aria-pressed="true"`: `--us` border on a `--us-soft` ground.
- The result line is `.nr-result` plus `.nr-deal` (green: "trato a 112 · excedente 0,97") or `.nr-walk` (red: "retirada · 0").
- Numbers use a Spanish decimal comma.
